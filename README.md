# Water Waste & Usage Tracker

## Description

The Water Waste & Usage Tracker is a Python program designed to help
households monitor their water consumption and estimate water waste.

The program collects information about household size, the number of
days being tracked, total water usage, and estimated water waste.

## Statistics

The program calculates:

- Average daily water usage
- Total water usage per person
- Water waste percentage
- Potential water savings

## Purpose

The purpose of this project is to increase awareness of household
water consumption and encourage responsible water-use habits.

## Python Concepts

This project demonstrates:

- try
- except
- finally
- User input
- Input validation
- Variables
- Arithmetic calculations
- Conditional statements
- Formatted output

## How to Run

Run the following command:

python water_waste_tracker.py
